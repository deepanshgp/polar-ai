# Data Lineage

## Phase 3 harmonisation status

The final OSI SAF native projection/grid is pending a verified provider file. No EPSG, origin, spacing, shape, date range, or variable metadata is asserted here. Once the file is available, `config/domain.yaml` must be populated from its attributes. Planned harmonisation is bilinear interpolation for continuous ERA5/current fields and daily UTC mean aggregation; no gap filling is performed.

**Why synthetic:** Real OSI SAF Level-3 data were not obtained in Phase 2.
Public NSIDC/NIC download endpoints returned 404; `copernicusmarine` package
was not available in the container image.  See `DECISIONS.md §Phase 4`.

**Path to real data:**
1. Obtain OSI SAF sea-ice concentration daily files (product OSI-401-b or
   OSI-450) via Copernicus Marine Service or EUMETSAT CODA.
2. Read native projection from file headers; populate `config/domain.yaml`.
3. Re-run `scripts/build_fixture_dataset.py` (or a real pipeline) to produce
   a replacement `harmonised.npz`.
4. Re-run `scripts/run_baselines.py` — the harness requires no code changes.
5. Commit new `results/baselines.json` and update `docs/EVALUATION.md`.
