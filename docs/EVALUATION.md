## What the numbers mean (and don't mean)

Because the data are synthetic, the fixture numbers above **measure harness
correctness**, not real-world skill:

- Damped persistence beats persistence in the fixture because the seasonal
  cycle is exactly cosine — this is expected and intended.
- Constant-velocity beats stationary because the synthetic trajectories have
  constant drift — again, expected by construction.
- IIEE values are large because the fixture grid is coarse (~100 km cells).

These numbers **are not a claim about Antarctic sea-ice predictability**.
They are a gate: if the metrics had been nonsensical (e.g. negative MAE,
or skill > 1) the harness would be broken.
